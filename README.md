# AeroSim

![AeroSim](aerosim.png)

AeroSim is a Windows desktop application for simulating and visualizing airflow around obstacles. It displays the flow in a 3D view using particles and streamlines.

## Requirements

- Windows
- .NET 8 SDK

## Build and run

From the project directory, run:

```powershell
dotnet restore AeroSim.sln
dotnet build AeroSim.sln
dotnet run --project AeroSim.csproj
```
